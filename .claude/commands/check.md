프로젝트의 모든 HTML 파일을 다음 항목에 대해 점검하라.

## 점검 항목

1. **제목**: 각 HTML 파일에 `<title>` 태그가 있고 비어 있지 않은지, 페이지 내용과 맞는지 확인한다.
2. **깨진 링크**: 모든 `<a href>`, `<img src>`, `<link href>`, `<script src>` 경로를 수집하고, 로컬 경로가 실제 존재하는 파일을 가리키는지 확인한다. (외부 URL은 형식만 확인하고 실제 요청은 보내지 않는다 — 이 프로젝트는 정적 파일 전용이다.)
3. **콘솔 에러**: 각 HTML 파일의 인라인/연결된 JavaScript를 검토하여 실행 시 에러를 일으킬 코드(정의되지 않은 변수·함수 참조, 존재하지 않는 DOM id 참조, 문법 오류 등)가 있는지 정적으로 분석한다. 브라우저 도구를 사용할 수 있다면 실제로 페이지를 열어 콘솔 에러를 읽어 확인한다.

## 보고 형식

점검이 끝나면 결과를 아래와 같은 표로 정리해서 보고한다.

| 파일 | 제목 | 링크 | 콘솔 에러 | 판정 |
|------|------|------|-----------|------|
| index.html | ✅ | ✅ | ✅ | 통과 |
| study.html | ✅ | ❌ 깨진 링크 2개 | ✅ | 수정필요 |

- 판정은 **통과** 또는 **수정필요** 두 가지만 사용한다.
- 표 아래에 "수정필요" 항목별로 구체적인 문제 위치(파일:줄번호)와 수정 방법을 설명한다.
- 문제를 발견해도 바로 고치지 말고, 먼저 보고만 하고 사용자의 지시를 기다린다.
